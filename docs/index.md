# espalier provider

Manage resources of [Apple's `container` runtime](https://github.com/apple/container)
on macOS: networks, volumes, images, containers, machines and local Kubernetes
clusters. The provider drives the
`container` command line tool, which must be installed; it never starts the
runtime itself (`container system start`).

Each provider release is verified against one `container` version and warns
in every plan when another one is installed; the
[compatibility table](https://github.com/thorstenpfister/terraform-provider-espalier#compatibility)
lists them.

**Why "espalier"?** An espalier is a fruit tree trained to grow flat along a
frame: structure declared for something that grows on its own, which is what
a configuration does for containers. The name also keeps clear of Apple's
trademarks.

espalier is not affiliated with or endorsed by Apple Inc.

## Example Usage

```terraform
terraform {
  required_providers {
    espalier = {
      source = "thorstenpfister/espalier"
    }
  }
}

provider "espalier" {
  # Optional: size the builder container that runs espalier_image_build.
  # It is stopped after the builds unless keep_running = true.
  builder = {
    cpus   = 4
    memory = "4G"
  }
}
```

## Schema

### Optional

- `builder` (Attributes) The runtime's builder container, which runs `espalier_image_build`s. The provider starts it for a build and stops it again when no build is left running, unless it was already running before. Setting `cpus` or `memory` recreates a running builder of another size. (see [below for nested schema](#nestedatt--builder))
- `cli_path` (String) Path to the `container` command line tool. Defaults to `container`, looked up on `PATH`.

### Nested Schema for `builder`

Optional:

- `cpus` (Number) CPUs of the builder. Defaults to 2.
- `keep_running` (Boolean) Keep the builder running after the builds, which makes the next run's builds start a few seconds sooner. Defaults to `false`.
- `memory` (String) Memory of the builder in bytes, with an optional `K`, `M`, `G`, `T` or `P` suffix. Defaults to `2G`.
